## ตอบแล้ว (Day 3)

**1. pipe (|) คืออะไร ทำงานยังไง**
เอาผลลัพธ์ของคำสั่งฝั่งซ้าย ส่งต่อไปเป็น input ให้คำสั่งฝั่งขวาทันที โดยไม่ต้องสร้างไฟล์กลาง
ทำให้ต่อหลายคำสั่งเป็นสายพานเดียวได้ เช่น `grep "Failed" logs/auth.log | awk '{print $9}' | sort | uniq -c`
ถ้าไม่มี pipe ต้องเซฟผลลัพธ์แต่ละขั้นเป็นไฟล์ก่อน แล้วค่อยเปิดไฟล์นั้นมาทำต่อ ยุ่งยากกว่ามาก

**2. ทำไม grep ต้องใส่คำในเครื่องหมายคำพูด**
ไม่ได้บังคับเสมอไป (คำเดี่ยวไม่มีช่องว่างไม่ใส่ก็ได้) แต่ต้องใส่เมื่อคำที่หามีช่องว่าง เช่น
`grep "invalid user" logs/auth.log` — ถ้าไม่ใส่เครื่องหมายคำพูด terminal จะตีความว่า "invalid"
กับ "user" เป็นคนละ argument กัน ทำให้คำสั่งพังหรือทำงานผิดจากที่ตั้งใจ เครื่องหมายคำพูดบอกว่า
ทั้งหมดนี้คือข้อความเดียวกัน ห้ามแยก

**3. wc -l กับ wc -1 ต่างกันยังไง**
ไม่ใช่แค่หน้าตาตัวอักษรต่างกัน (L กับเลข 1) แต่ความหมายคนละเรื่องเลย — `-l` (L ตัวเล็ก) คือ flag
ที่บอกให้ wc นับจำนวน "line" (บรรทัด) ส่วน `-1` (เลขหนึ่ง) ไม่ใช่ flag ที่ wc รู้จักเลย พิมพ์ผิดแล้ว
ระบบจะฟ้อง error ทันที (`unexpected argument '-1' found`) เจอ error นี้จริงระหว่างทำ Day 3
